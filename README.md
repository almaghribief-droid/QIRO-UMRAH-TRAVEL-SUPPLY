# QIRO Umrah & Travel Supply

Website resmi QIRO untuk kebutuhan perlengkapan jamaah dan travel Umrah.

## Kategori
- Tas jamaah dan travel
- Koper perjalanan
- Peci dan songkok
- Topi custom
- Seragam travel
- Paket perlengkapan

## WhatsApp
Nomor WhatsApp belum dipasang. Edit konstanta `QIRO_WHATSAPP` di bagian akhir `index.html`, isi dengan nomor internasional tanpa tanda plus/spasi, misalnya `62812xxxxxxxx`.

## Aktifkan GitHub Pages
1. Buka **Settings** repositori.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
5. Tunggu beberapa menit sampai URL Pages muncul.

Catatan: katalog menampilkan kategori layanan, bukan klaim bahwa semua barang tersedia sebagai stok. Harga, ketersediaan, dan waktu produksi dikonfirmasi saat penawaran.
